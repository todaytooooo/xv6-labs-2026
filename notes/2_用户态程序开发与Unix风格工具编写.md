## 三、实验要点
1. sleep   进程的状态
⚫ 功能: 调用pause 系统调用实现暂停功能，暂停时间ticks通过命令行传入；
⚫ 原理：xv6 内核通过时钟中断维护 ticks 计数，sleep/pause 系统调用会将进程置于阻塞状态，直到指定ticks 数耗尽后由内核唤醒。
⚫ 提示与说明：
➢ 命令行参数：argc/argv 解析与 atoi 类型转换
➢ 状态转换：调用pause 后进程从 RUNNING 改成 SLEEPING。时钟中断推进 ticks 并把等待的进程从 SLEEPING 改成 RUNNABLE
2. 编写程序primes，寻找2-35之间素数
⚫ 功能：实现一个并发的McIlroy 素数筛法程序，输出 2 到 35 之间的所有素数。
⚫ 提示：用pipe和fork系统调用递归创建进程流水线实现McIlroy 筛法。每个进程负责过滤一个特定的素数：每个进程从管道读取数字，第一个数就是素数并打印，然后把后续不能被该素数整除的数字通过管道传给下一个子进程。
3. 编写程序sixfive
⚫ 功能：将文件sixfives.txt中被5或6整除的数字打印出来。即判断sixfives.txt文件中分隔符（" -\r\t\n./,"）间的是否为数字，将符合要求的数字打印。
⚫ 提示：使用read系统调用读取文件，每次读一个字符；使用strchr()函数检查字符是否为分隔符；文件开头和结尾是隐式分隔符
4. 编写程序find
⚫ 功能：编写一个简化版的 UNIX find 程序：在目录树中查
找所有名称与指定名称匹配的文件
⚫ 提示： 利用open、read、fstat 系统调用实现本功能；参
考 user/ls.c 的代码，学习如何读取目录内容；使用递归实
现 find 程序，使其能够进入子目录（遍历目录树），但要
跳过 . 和 .. 防止无限递归；需使用 strcmp() 函数进行字符
串比较。
选做：给 find 命令增加一个 “-exec cmd” 选项
⚫ 当 find 找到每个匹配的文件 file 时，不再打印该文件的名
称，而是执行命令 cmd file（即把找到的文件路径作为参数
，传给 cmd 执行）
